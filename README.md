# 🔐 Password Generator GUI using Python(tkinter)

A simple and beginner-friendly Password Generator application built using Python and Tkinter GUI.

This application generates strong random passwords using:
- Uppercase letters
- Lowercase letters
- Numbers
- Special symbols

Users can also save generated passwords into a file.

---

# 🚀 Features

✅ Generate secure random passwords  
✅ User-friendly GUI using Tkinter  
✅ Choose custom password length  
✅ Save passwords to a text file  
✅ Error handling for invalid inputs  
✅ Beginner-friendly Python project
